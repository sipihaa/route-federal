# Route Federal

Курсовая работа по дисциплине «Разработка мобильных приложений». Android-приложение на Kotlin для поиска маршрутов на поездах, электричках и автобусах между городами внутри региона и между регионами.

## Возможности

- офлайн-карта с границами и названиями регионов России;
- выбор города отправления, города назначения и даты поездки;
- поиск до трёх вариантов маршрута с учётом расписания, дней курсирования и времени на пересадку;
- подробный просмотр маршрута: рейсы, станции пересадок, время ожидания;
- импорт файла расписания с проверкой, при ошибке сохраняются прежние данные.

Расписание берётся из API Яндекс Расписаний. Загружены направления между городами Москвы, Московской, Владимирской и Нижегородской областей: 6 городов, 18 станций, около 1800 рейсов на одну неделю.

## Сборка и запуск

Нужны JDK 17 и Android SDK 35. Минимальная версия Android — 10 (API 29).

Проще всего открыть проект в IntelliJ IDEA или Android Studio и запустить конфигурацию `app`. Из терминала:

```sh
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Готовый APK можно также просто скопировать на телефон и установить.

## Данные расписания

Файл расписания не входит в APK и в репозиторий: по условиям API Яндекс Расписаний данные можно хранить только как временный кэш.

1. Получить ключ API Яндекс Расписаний, скопировать `.env.example` в `.env.local` и вписать ключ.
2. Загрузить расписание: `python3 tools/download_yandex_network.py --download`. Направления и даты задаются в `data/yandex/network-plan.json`.
3. Подготовить файл: `python3 tools/prepare_yandex_timetable.py`. Скрипт проверяет данные и создаёт `.yandex-cache/timetable.json`.
4. Перенести файл на телефон и открыть его в приложении: «Данные» → «Импортировать расписание».

Кэш действует около недели, после этого расписание нужно загрузить заново.

## Формат файла расписания

JSON с полем `schemaVersion: 1` и тремя разделами:

- `source` — источник, дата получения, период расписания (`validFrom`, `validUntil`) и срок действия кэша (`expiresAt`);
- `stops` — станции: идентификатор, название, город, координаты, часовой пояс, минимальное время пересадки;
- `trips` — рейсы: вид транспорта (`BUS`, `TRAIN`, `SUBURBAN`), дни курсирования, дополнительные и исключённые даты и список остановок. Время на остановках указано в минутах от полуночи дня отправления рейса.

Пример с тестовыми данными: `app/src/androidTest/assets/ui_timetable.json`.

## Тесты

```sh
./gradlew :app:testDebugUnitTest              # unit-тесты алгоритма
./gradlew :app:connectedDebugAndroidTest      # UI-тесты, нужен эмулятор или телефон
python3 -m unittest discover -s tools -p 'test_yandex_*.py'
```

Тест с реальными данными выполняется, если перед сборкой положить файл расписания в `.yandex-cache/android-test-assets/yandex_timetable.json`, иначе он пропускается.

## Ограничения

- расписание загружено только для выбранных направлений и на одну неделю;
- наличие билетов и задержки рейсов не учитываются;
- расписание обновляется скриптами на компьютере, а не из самого приложения.
