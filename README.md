# Route Federal

Курсовая по разработке мобильных приложений на Kotlin. Android 10 и выше, Jetpack Compose. Основное задание — `route_federal.pdf`.

**Текущая версия — рабочий прототип, не завершённая курсовая с покрытием всей России.** Карта и поиск работают офлайн; встроены только два реальных расписания Ростов — Ейск и обратно по выходным 12–27 сентября 2026 года. Указаны источник и пределы снимка. Авиации, внутригородских перевозок и переходов между разными вокзалами нет.

## Запуск на этом Mac

SDK и эмулятор уже подготовлены в локальных папках проекта. В терминале IntelliJ IDEA из корня проекта:

```sh
source tools/android-env.sh
./gradlew :app:assembleDebug
emulator -avd RouteFederal_API29 -gpu host -no-snapshot
```

В другом терминале, также из корня проекта:

```sh
source tools/android-env.sh
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell am start -n ru.milin.routefederal/.MainActivity
```

Для проверки реального снимка выбрать **Ростов-Главный (Пригородный) → Ейск**, дату **12.09.2026**. Ожидается один вариант **3 ч 13 мин**, без пересадок. В обратном направлении — **2 ч 48 мин**. На карте кнопка «К выбранным точкам» приближает выбранные станции.

Полная инструкция, включая плагины IDEA и установку SDK на другом компьютере: [docs/SETUP.md](docs/SETUP.md). Первая сборка требует интернета для инструментов и библиотек; установленное приложение использует локальные ресурсы и не запрашивает разрешение на доступ в интернет.

## Проверки

```sh
source tools/android-env.sh
./gradlew :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

Последняя команда требует запущенного эмулятора. Есть 13 unit-тестов алгоритма и два инструментальных теста: UI-сценарий топ-3 и проверка реального снимка с защитой от повреждённого импорта. Искусственные случаи используются только внутри тестов. Фактические результаты и оставшиеся ограничения: [docs/validation](docs/validation).

- ТЗ и отчёт находятся в исходных DOCX в корне. Они заполняются по фактически выполненным этапам.

Обновление выполняется импортом проверенного JSON через раздел «Данные». Автоматической общей выгрузки всей России нет. `tools/import_mintrans.py` разбирает оригинальные XLSX и создаёт аудит исключений; его промежуточные часы ещё не являются готовыми рейсами для приложения. `tools/prepare_rail_snapshot.py` воспроизводит встроенный реальный снимок из сохранённых сведений СКППК. Для этих подготовительных скриптов нужен Python 3; для самого Android-приложения он не нужен.

Ограничения: нет подтверждённой базы всех направлений, нормы пересадок требуют реальных источников, JSON ограничен 20 МБ, национальная производительность не проверена, состояние после уничтожения процесса не восстанавливается. Ручная замена снимка реализована; фоновое обновление остаётся желательным развитием.
